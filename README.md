## Tech Stack

- **Hosting:** Vercel

## Getting Started

### Prerequisites

- Node.js (LTS)
- npm

### Local Development

```powershell
git clone https://github.com/r3lic-pnw/van-vogt-construction.git
Set-Location .\van-vogt-construction
npm install
npm run dev
```
Then open http://localhost:3000.
